# DigitalnePozivnice

ASP.NET Core MVC (.NET 10) sajt za digitalne svadbene pozivnice (Save the date / Premium / Exclusive), 6 jezika (sr, hr, bs, sl, de, en).

## Pokretanje
1. Podesi konekciju u `appsettings.json` (SQL Server) i pokreni SQL skripte iz `SQL/` redom.
2. Pokreni `skini-fontove.ps1` (preuzima fontove u `wwwroot/fonts`).
3. `dotnet run` ili F5 u Visual Studiju.

Privatni projekat, sva prava zadrzana.
